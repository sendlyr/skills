# Practica: a synthetic trial app with known answers

Practica is a made-up language-learning app with a 7-day free trial that converts to paid automatically. Everything here is generated by [`datasets/generate_synthetic.py`](../../datasets/generate_synthetic.py) from a fixed seed. No real users are involved.

The world is built so every skill has a right answer to find. The planted truths are listed in [`answer_key.json`](answer_key.json), and the test suite checks every script against them.

| Folder | What's in it | Try it with |
|---|---|---|
| `observational/` | 5,000 trial accounts (Jan–May 2026), their events, and day-3 facts | `finding-leading-indicators`, `designing-lifecycle-states` |
| `states/` | A good 3-state model and a flawed legacy model with five planted problems | `designing-lifecycle-states` |
| `experiment/` | A well-run 50/50 holdout of state-routed onboarding emails (7,000 users) | `writing-decision-readouts`, `designing-state-journeys` |
| `experiment-broken/` | The same experiment run badly: an outage, sends to already-active users, cap drift, retries inside 24h, stale renders, control contamination | `writing-decision-readouts`, `designing-state-journeys` |
| `emails/` | Claim rules, nine AI-written drafts (two clean, one with warnings, six blocked) and a leaky group template | `grounding-lifecycle-emails` |

## What's planted

**The setup step is the cliff.** Users who never set a goal almost never pay. This mirrors Typesy Homeschool, where "parent adds a child" was the real indicator.

**Each other behavior plays a role:**

| Behavior | Planted as |
|---|---|
| `lesson_completed` | Supporting signal. One lesson separates almost as well as three |
| `email_opened` | Confounded decoy: motivated users open more email and also pay more |
| `app_opened` on day 0 | Too broad: almost everyone does it |
| `billing_page_viewed` | Leak bait: it mostly happens after paying |
| `streak_reminder_shown` | Done by the system, not the learner |

**Other conditions:**
- The newest signups are too young for a 14-day outcome, so they are immature.
- About 1.5% of day-3 facts have a tracking gap (`UNOBSERVABLE`).
- About 1% of experiment outcomes are blank (unmeasured).

Regenerate with:

```bash
python3 datasets/generate_synthetic.py --out examples/practica
python3 datasets/generate_synthetic.py --out examples/practica --check   # verify nothing drifted
```
